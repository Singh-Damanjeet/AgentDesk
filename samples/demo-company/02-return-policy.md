# AcmeFlow Return Policy

AcmeFlow sells software subscriptions and does not ship physical products.
There is no physical-product return process for AcmeFlow subscriptions.

If a customer purchased an eligible add-on or hardware bundle through an
authorized AcmeFlow partner, the partner's return terms apply. Contact the
partner shown on the order confirmation before sending anything back. For
subscription charges, use the separate Refund Policy and Cancellation Policy.

Questions about a specific order or refund status require account access that
the support assistant does not have. Those requests are sent to a human
support teammate.
