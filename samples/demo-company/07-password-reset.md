# AcmeFlow Password Reset

To reset a password, open the AcmeFlow sign-in page and select **Forgot your
password?** Enter the email address used for the workspace. If the address is
registered, AcmeFlow sends a reset link that expires after 30 minutes.

Check spam or corporate email filtering if the message does not arrive. Request
one fresh link after waiting a few minutes; only the newest link remains valid.
Never send a password or reset token to support.

Support cannot create a password or disclose whether an unverified email is
attached to an account. If the reset flow still fails, a human teammate can
help after verifying workspace ownership.
